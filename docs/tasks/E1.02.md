# E1.02 — Aplicação desktop funcional

- Estado: concluída
- Commit: `b113388` — `feat: create functional desktop shell` (2026-11-13)

## Objectivo

Configurar Electron, React, TypeScript e Vite numa aplicação desktop que arranque com segurança e apresente uma interface navegável, exclusivamente demonstrativa.

## Entregue

- Processo principal (`apps/desktop/src/main/main.ts`) com bloqueio de novas janelas e de navegação externa, e modo `--smoke-test`.
- Opções de janela seguras isoladas em `window-options.ts` (`contextIsolation`, `sandbox`, `webSecurity`; sem `nodeIntegration` nem conteúdo inseguro).
- Preload CommonJS (`preload.cts` → `dist-electron/preload.cjs` via `vite.preload.config.ts`) que expõe apenas `kilDesktop.runtime.platform`, de forma imutável.
- Renderer React: `App.tsx`, `Sidebar`, `Dashboard`, `ModulePage`, `navigation.ts` (8 destinos) e `styles.css`.
- Scripts `dev`, `build`, `smoke` e `typecheck` em `apps/desktop/package.json`; `scripts/run-electron.mjs`.
- Testes: `tests/desktop-security.test.ts` (2) e `tests/desktop-ui.test.tsx` (2), com `tests/setup.ts`.
- Script raiz `test:desktop`; README e `docs/architecture.md` actualizados.

## Fora de âmbito

Persistência, autenticação, dados reais, operações comerciais e ligação à API local. Todos os indicadores são demonstrativos.
