## Alteração de configuração (`vitest.config.ts`)

Com o Vitest 5 sem mais alterações, 35 testes falharam com `expected TenantContextError … to be an instance of TenantContextError`. Os testes importavam o domínio a partir de `src/`. O código do pacote `database`, testado através de `@kil-business/shared-types`, passou a resolver para `dist/`, porque o ambiente `node` do Vitest 4+ usa o ambiente `ssr` do Vite e este, desde o Vite 6, não herda `resolve.conditions`. A mesma classe existia em duas cópias.

Correcção, conforme a documentação oficial: acrescentar `ssr: { resolve: { conditions: ['source', 'import', 'default'] } }`, mantendo `resolve.conditions: ['source']` para o ambiente jsdom (D-078). Assim preserva-se D-037/PD-08: os testes exercem o código-fonte, sem depender de `dist/`.

Nenhum teste, asserção, regra de negócio, *script*, alias, *setup*, *fixture* ou ambiente foi alterado. A raiz fixa (D-022/PD-01) mantém-se.
