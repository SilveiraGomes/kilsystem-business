# E1.08 — API local segura e integração Electron

- Estado: **planeada, não autorizada**. Não iniciar sem autorização explícita do responsável do projecto.
- Origem: planeamento inicial definido na autorização de E1.06.

## Objectivo planeado

Expor o serviço local através de uma API REST em Fastify (D-066), autenticada (E1.07) e isolada por empresa, e ligar a aplicação Electron a essa API.

## Âmbito indicativo

- API REST em `services/local-api`, apenas em loopback no modo A (D-062), com autenticação e autorização obrigatórias.
- Contratos de pedido e resposta validados nas fronteiras; erros sem dados sensíveis.
- Integração com o desktop através do preload, com API mínima e sem expor repositórios ao renderer (D-047). Inclui a resolução da PD-04 (“Sistema local disponível”).
- Testes de contrato da API e testes de acesso cruzado entre empresas.

## Pré-requisitos

- **PD-17**: o Electron 33 está fora de suporte e tem alertas de segurança altos. A actualização deve acontecer antes desta integração, numa tarefa própria autorizada.
- E1.07 concluída.

## Decisões a obter antes de iniciar

- Transporte em loopback (porta TCP, *named pipe* ou outro), descoberta e protecção contra outros processos locais.
- Quem arranca o serviço durante o desenvolvimento e em instalação (o serviço Windows fica para E1.10, D-065).
- Política de versões da API.

## Fora de âmbito previsto

HTTPS para terminais remotos (modo B, D-063), serviços centrais e instaladores.
